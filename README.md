# PLAYDOT 玩点

随时玩一点，快乐多一点。手机优先、免登录的十款网页小游戏，沿用原仓库和 GitHub Pages。

**在线游玩：<https://logic050122-cmyk.github.io/dual-axis-dodge/>**

维护前先读 [AGENTS.md](AGENTS.md) 和 [PROJECT_LOG.md](PROJECT_LOG.md)。

| 游戏 | 玩法与模式 |
| --- | --- |
| 反应力测试 | 轻松档等信号点击；挑战档判断左右箭头并按对应按钮，记录方向失误与抢跑 |
| 精准点击 | 五关连击守关：成组靶、双击护盾、避开叉号，关间回血或加分；经典练习保留左右交替/连中反馈与原成绩 |
| 记忆翻牌 | 配对图案，不限时，6/8 对；挑战档先看全牌 3 秒，并记录连对与失配 |
| 双轴闪避 | 一人双手独立控制，横屏，完整镜像；经典/自由及起步等级保留 |
| 节奏记忆 | 每轮增加一个信号；轻松可重看/重试，挑战结算指出失误拍并可练习同一轮；不限时作答，可选声音 |
| 找出不同 | 轻松十关找唯一形状；挑战 45 秒依次练习看轮廓、忽略颜色、找形状＋圆点组合 |
| 一笔连线 | 固定可解路线，4/6 关，每边走一次；通关逐关解锁练习起点，支持滑动/点按、提示、撤销与原题重置 |
| 节奏点击 | 纯视觉大按钮/空格键；轻松档 12 个等拍，挑战档 4×4 拍固定长短乐句；窗口 ±280/210ms，卡顿安全暂停 |
| 颜色分类 | 3/4 类，各三块，两个备用盒容量；显示精确最短步数、可选路线提示与整局绕路纪录，不限时 |
| 迷你迷宫 | 可解的 5×5 / 7×7 迷宫，方向按钮/键盘/滑动，可提示下一格；不限时，按路线效率计分 |

首页有反应力、记忆力、观察力、逻辑、休闲分类，可从当前分类随机打开一款游戏，并提供最近四款入口和本机最佳记录。各游戏保留独立视觉元素，采用统一按钮、结果卡和返回导航。成绩只供娱乐，不作能力诊断。

## 运行与验证

无构建步骤、框架、包安装或后端。从仓库根目录运行：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000/`。不要用 `file://` 测离线功能。

```bash
for test in tests/*.mjs; do node "$test" || exit 1; done
```

目前 25 套回归，含旧双轴全套、生成可解性、Node VM 真实脚本、结构 DOM 集成和 SW 策略。**这不是浏览器视觉、真实手机触屏或已安装 PWA 验收。** 详见 [验收记录](docs/ACCEPTANCE.md)。

## 文件与数据

- `index.html`：大厅、四个早期游戏、共享模式/记录/定时器。
- `arcade-games.js` / `arcade-games.css`：五个后续游戏的规则与薄适配，不用通用引擎重写旧游戏。
- `games/dual-axis-dodge/`：原双轴，运行脚本保留；菜单和竖屏提示可返回大厅。
- `sw.js`：预缓存大厅、JS/CSS 和双轴资源；独立导航回退；JS/CSS 网络优先并离线回退。
- `tests/`：生产规则与实际脚本回归，辅助 DOM/时钟仅供 Node 验证。
- [设计规范](docs/PRODUCT_DESIGN.md)、[开发日志](PROJECT_LOG.md)、[验收记录](docs/ACCEPTANCE.md)。

大厅保留 `playdot:v1:` 前缀，`游戏:模式` 分开存最佳，`recent` 存最近四个游戏标识。双轴原有 `dualAxisBest` / `dualAxisLevelBests` 等键不迁移，首页只读展示且区分模式/起步等级。禁用或写入失败时仍可玩，大厅成绩保留会话最佳，并标明关页可能丢失；无效数字不会阻止新纪录。

没有账号、在线排行榜、广告或追踪。离线需先成功在线访问并缓存；浏览器清理站点数据会移除记录与缓存。

## 发布

main 由既有 GitHub Pages 自动发布；Input regression 和 Project log guard 检查功能更新。每个里程碑独立提交，发布后核对 Actions 与公开资源。禁止强推或绕过保护规则。

扩展脚本未加载时，大厅会标明暂未加载的游戏并提供重试；已加载的四款仍可玩，最近记录不会因一次加载失败丢失。

可玩性改造从精准点击开始，当前规则与取舍见 [玩法审查](docs/GAMEPLAY_REVIEW.md)。功能齐全与自动化通过不代表娱乐性已经验收。
