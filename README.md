# PLAYDOT 玩点

随时玩一点，快乐多一点。手机优先、免登录的十款网页小游戏，沿用原仓库和 GitHub Pages。

**在线游玩：<https://logic050122-cmyk.github.io/dual-axis-dodge/>**

维护前先读 [AGENTS.md](AGENTS.md) 和 [PROJECT_LOG.md](PROJECT_LOG.md)。

| 游戏 | 玩法与模式 |
| --- | --- |
| 反应力测试 | 等信号点击，抢跑不计成绩，多轮中位数 |
| 精准点击 | 点击目标，按命中速度和准确率计分 |
| 记忆翻牌 | 配对图案，不限时，6/8 对 |
| 双轴闪避 | 一人双手独立控制，横屏，完整镜像；经典/自由及起步等级保留 |
| 节奏记忆 | 每轮增加一个信号；轻松可重看/重试，挑战点错结束；不限时作答，可选声音 |
| 找出不同 | 唯一形状差异，3×3→4×4；轻松十关不限时，挑战 45 秒 |
| 一笔连线 | 固定可解路线，4/6 关，每边走一次；滑动/点按、提示一步、撤销、原题重置 |
| 节奏点击 | 纯视觉 12/16 拍，大按钮/空格键；窗口 ±280/210ms，卡顿安全暂停 |
| 颜色分类 | 3/4 类，各三块，两个备用盒容量；逆向生成有解，撤销/原题重置，不限时 |
| 迷你迷宫 | 可解的 5×5 / 7×7 迷宫，方向按钮/键盘/滑动；不限时，按路线效率计分 |

首页有反应力、记忆力、观察力、逻辑、休闲分类、最近四款入口和本机最佳记录。各游戏保留独立视觉元素，采用统一按钮、结果卡和返回导航。成绩只供娱乐，不作能力诊断。

## 运行与验证

无构建步骤、框架、包安装或后端。从仓库根目录运行：

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000/`。不要用 `file://` 测离线功能。

```bash
for test in tests/*.mjs; do node "$test" || exit 1; done
```

目前 18 套回归，含旧双轴全套、生成可解性、Node VM 真实脚本、结构 DOM 集成和 SW 策略。**这不是浏览器视觉、真实手机触屏或已安装 PWA 验收。** 详见 [验收记录](docs/ACCEPTANCE.md)。

## 文件与数据

- `index.html`：大厅、四个早期游戏、共享模式/记录/定时器。
- `arcade-games.js` / `arcade-games.css`：五个后续游戏的规则与薄适配，不用通用引擎重写旧游戏。
- `games/dual-axis-dodge/`：原双轴，运行脚本保留；菜单和竖屏提示可返回大厅。
- `sw.js`：预缓存大厅、JS/CSS 和双轴资源；独立导航回退；JS/CSS 网络优先并离线回退。
- `tests/`：生产规则与实际脚本回归，辅助 DOM/时钟仅供 Node 验证。
- [设计规范](docs/PRODUCT_DESIGN.md)、[开发日志](PROJECT_LOG.md)、[验收记录](docs/ACCEPTANCE.md)。

大厅保留 `playdot:v1:` 前缀，`游戏:模式` 分开存最佳，`recent` 存最近四个游戏标识。双轴原有 `dualAxisBest` / `dualAxisLevelBests` 等键不迁移，首页只读展示且区分模式/起步等级。禁用存储时仍可玩，后续游戏保留会话最佳。

没有账号、在线排行榜、广告或追踪。离线需先成功在线访问并缓存；浏览器清理站点数据会移除记录与缓存。
