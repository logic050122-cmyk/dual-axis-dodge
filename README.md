# PLAYDOT 玩点 — 电竞与脑力小游戏

沿用原双轴闪避 GitHub 仓库和 Pages 地址，不再建仓库。

游戏大厅位于根目录 index.html，包括反应力测试、精准点击、记忆翻牌、节奏记忆、找出不同，以及通往原双轴闪避的入口。
原双轴闪避完整位于 games/dual-axis-dodge/；其操控、镜像、音频和本机记录键值不改。
大厅四款游戏各有轻松与挑战模式，适合儿童和成年人。节奏记忆从 1 个色块开始，每轮多记 1 个；轻松可重看与重试，挑战点错结束，均不限时作答。声音默认关闭，后台/暂停后需主动继续并从本轮开头重播。个人纪录仅存浏览器 localStorage，没有登录、广告追踪或在线排行榜。游戏只供娱乐，非智商或医疗测评。

运行：在根目录执行 python3 -m http.server 8000 后访问 localhost:8000。
测试：`for test in tests/*.mjs; do node "$test" || exit 1; done`，含大厅、节奏记忆与原双轴完整回归。节奏测试在 Node VM 中运行实际脚本与可控时钟，不是浏览器或真机验收。
离线：根 sw.js 分别缓存大厅和双轴游戏；不可用 file:// 模式测试 PWA。
发布：现有 main 自动部署 GitHub Pages，主页变成 PLAYDOT，大厅的双轴卡片链接 games/dual-axis-dodge/。

产品设计与里程碑：[docs/PRODUCT_DESIGN.md](docs/PRODUCT_DESIGN.md)。所有改动先读 AGENTS.md 与 PROJECT_LOG.md。

新增游戏位于 `arcade-games.js` / `arcade-games.css`，沿用大厅的模式、记录与会话清理；新增文件纳入日志检查、CI 与离线缓存。找出不同每题保证仅一个形状不同，最多 4×4；轻松十关不限时，挑战 45 秒。

大厅支持分类、最近四款游戏和全部本机最佳记录；双轴成绩按原键只读展示，区分经典/自由与起步等级。`playdot:v1:recent` 仅存游戏标识，不记录个人信息。

一笔连线：轻松四关/挑战六关，不限时；从指定起点每边走一次，支持点按、单指滑动、撤销和重开。所有关卡保留可验证的完整解。

节奏点击：12/16 拍的纯视觉节奏，窗口 ±280/210ms，不依赖音频；大按钮或空格键输入，明显渲染中断会安全暂停，继续前有准备时间。减少动态模式保留文字与进框信号。

颜色分类：3/4 类图块，各带颜色、形状和编号，比类别数多两个盒子，保留空余容量；逆向生成并保留合法解，默认不限时，支持撤销及原题重置。
